01 · Normalize away arbitrary score scale

current PDF pp. 2–4

Read with this purpose: define a positive scale-invariant measure of signed vote agreement, then use it to distinguish algebra, voting, and function-class views.

The normalized functional margin

backbone

For a vote FT(x) = Σ αtht(x), the signed score on a labelled observation is yFT(x). Raw signed scores change when every coefficient is multiplied by the same positive constant.

ρ(x,y) = yFT(x) / ‖α‖1,   ‖α‖1 = Σ|αt| > 0
ρ > 0positive signed agreement; the predicted sign is correct
ρ < 0negative signed agreement; the predicted sign is wrong
ρ = 0the tie rule still decides correctness

Why the range is [−1, 1]

Because |yht(x)| = 1, the triangle inequality gives

|yFT(x)| ≤ Σ|αt| = ‖α‖1

Dividing by the positive denominator gives −1 ≤ ρ(x,y) ≤ 1.

Why positive common scaling disappears

For c > 0,

ycFT(x) / ‖cα‖1 = ρ(x,y)

The raw score changes. The normalized agreement does not.

Conceptual checkpoint

  1. A positive-coefficient vote has ρ = 0.40. What are the correct and wrong coefficient shares? Does this imply that 70% of the classifiers are correct—or that the ensemble has a 70% probability of being correct?
  2. If negative coefficients are allowed, why use Σt|αt| rather than Σtαt?

Scale studio · same vote, different raw scale

interactive

Vote A has signed training scores (0.10, 0.50, 0.60, 0.80). Change c and compare the raw scores with the unchanged normalized margins.

Required note · scope of the claim

read now

The invariance statement is only for c > 0. The denominator must be nonzero. These conditions protect the definition without interrupting the main idea.

Minor edge case · negative scaling

For c < 0, the score sign reverses and predicted labels can change. This is outside the positive-rescaling invariance claim.

Domain note · zero coefficient vector

If every coefficient is zero, ‖α‖1 = 0 and the normalized margin is undefined. A zero score on one observation is different when the coefficient vector is nonzero.

Interpretation boundary · what ρ is not

A normalized margin is not automatically a probability of correctness and not a distance from an input-space decision boundary. It is a signed output-space agreement measure.

Course link · convex view next

When coefficients are nonnegative, normalization turns the vote into a convex combination. That is the function class used by the population margin bound.

02 · Turn a positive vote into weighted agreement

current PDF p. 5

Read with this purpose: rewrite a positive vote as a weighted average, then interpret the margin as correct share minus wrong share.

From coefficients to a convex combination

backbone

For the positive coefficients used in ordinary successful AdaBoost rounds, put A = Σtαt > 0 and λt = αt/A.

λt ≥ 0,   Σλt = 1,   FT(x)/A = Σλtht(x)

The normalized vote therefore belongs to conv(ℋ), the set of finite weighted averages of functions from the base class.

Correct sharecoefficient weight on classifiers with yht(x) = +1
Wrong sharecoefficient weight on classifiers with yht(x) = −1
Marginthe difference between those two shares
ρ = (1 − q) − q = 1 − 2q
The theorem boundary. The convex-hull interpretation uses nonnegative normalized weights. With signed coefficients, the absolute-value denominator still gives a range bound, but membership in the original convex hull needs a sign-closure condition.

Checkpoint

If ρ = 0.40, solve 1 − 2q = 0.40. Then explain why this is a share of coefficient weight, not a count of classifiers.

Required note · three views

read now

Keep these views together: algebraic normalization, weighted voting, and convex-hull membership. The next population bound uses the third view.

Counterexample · signed coefficients

A signed combination can have coefficients that do not form nonnegative weights summing to one. The absolute-value normalization controls scale, but it does not by itself place the function in conv(ℋ).

Forward link · margin theorem

The population theorem is stated for normalized votes in the convex hull of a fixed base class. Keep this scope visible when reading Block 04.

03 · Read the whole margin distribution

current PDF pp. 6–7

Read with this purpose: replace one-number summaries with the fraction of training rows whose margins lie at or below a chosen threshold.

Low-margin mass as a step function

backbone

For training margins ρ1, …, ρm, define

ρ̂θ = (1/m) Σ 1[ρi ≤ θ]
  • Increasing θ cannot remove a counted row.
  • The curve changes only when the threshold reaches a training margin.
  • Equality is included: a row with ρi = θ counts.
  • At θ = 0, the low-margin mass includes all nonpositive margins and is an upper bound on observed classification-error fraction under the declared tie rule.

Same training error, different distributions

Vote A has margins (0.10, 0.50, 0.60, 0.80). Vote B has (0.40, 0.50, 0.50, 0.60). Both classify all four rows correctly, but their curves cross.

04 · Read the population margin bound as a contract

current PDF pp. 8–10

Read with this purpose: distinguish training-curve evidence from fresh-draw population error and identify every condition carried by the theorem.

From a training curve to new-data evidence

backbone

Let 𝒟 generate independent labelled observations and let hf predict the sign of a normalized vote f, with +1 at a tie. A mistake requires a nonpositive signed score, so

R𝒟(hf) ≤ Pr(x,y)∼𝒟[yf(x) ≤ 0]
The theorem contract. Fix a binary base class ℋ with VC dimension d. Draw m ≥ 2d independent labelled examples. Choose δ ∈ (0,1) and θ ∈ (0,1]. With probability at least 1 − δ, the displayed guarantee holds simultaneously for every f ∈ conv(ℋ) and every allowed θ.
R𝒟(hf) ≤ ρ̂θ + C√(d log²(m/d)/(mθ²) + log(1/δ)/m)
Empirical termcounts training rows with margin ≤ θ
Complexity termpenalizes capacity, confidence, sample size, and small θ
Uniform eventthe vote may be selected from the sample within this stated class

Checkpoint

What does “uniform” buy us here? What does it not buy us? Name the fixed class, the random object, and the quantity that is still only an upper bound.

Required note · bound versus risk

read now

A smaller displayed upper bound is an ordering of bounds at a stated threshold. It is not proof that the actual population risks differ by the same amount.

Threshold tradeoff

As θ increases, the empirical term cannot decrease, while the inverse-θ² penalty decreases. Read the full expression.

Constant C is unspecified

The theorem gives dependence on the parameters. It is not a numerical error certificate obtained by setting C = 1.

Selection/evaluation link

Uniformity supports comparison inside the theorem event; it does not replace independent validation or test evidence when selecting a stopping round.

05 · Ask what AdaBoost actually chooses to decrease

current PDF pp. 11–15

Read with this purpose: separate the population theorem from the optimization rule, then derive one exact coordinate step under explicit conditions.

Coefficient space, weights, derivative, line search

backbone

Fix a finite dictionary ℋ = {h1, …, hN}. The variable is the coefficient vector β, not the input.

Fβ(x) = Σβjhj(x),   J(β) = (1/m)Σ exp(−yiFβ(xi))

A coordinate update is β ↦ β + aej. At the current β, reconstruct the normalized exponential weights

D(i) = exp(−yiFβ(xi)) / Σkexp(−ykFβ(xk))

For candidate hj, let εj be its weighted error. Then

∂J/∂βj = −J(β)(1 − 2εj)
Direction selection.

With both signs available, the steepest signed coordinate is the candidate with the largest absolute edge |1 − 2εj|.

Line search.

After choosing a direction with 0 < ε < 1/2, exact minimization gives

a* = ½ log((1−ε)/ε)
Conditions are part of the result. Exact greedy signed-coordinate selection needs a finite sign-closed dictionary, exact weighted-error minimization, a consistent tie rule, and exact line search. At ε = 0 the finite minimizer disappears; at ε = 1/2 the direction has zero edge.

Checkpoint

Does a positive edge alone prove that the selected classifier is the steepest coordinate? Which assumption lets the sign of the coordinate be chosen too?

Required note · two questions

read now

Block 04 asks what can be guaranteed for new data. This block asks what the algorithm chooses to decrease. The margin bound is not a premise of the coordinate-selection proof.

Notation bridge · α to β

Lecture 8 uses round-indexed αt. Here βj indexes a fixed dictionary function. Reusing a function changes its existing coefficient.

Sign closure

If the dictionary contains −h whenever it contains h, then allowing positive additions covers both coordinate signs.

Global optimum warning

Convexity and differentiability support the line search. One coordinate update need not reach a global optimum, and a finite minimizer need not exist in a separating direction.

06 · Follow the rows that receive large exponential mass

current PDF pp. 16–17

Read with this purpose: understand why low signed scores receive more attention and keep common scaling separate from an actual coordinate update.

Relative masses expose persistent difficulty

backbone

For signed scores si = yiF(xi), normalized row masses are proportional to exp(−si). For two rows, the denominator cancels:

D(i)/D(k) = exp(sk − si)

If one signed score is −1.2 and another is 1.6, the mass ratio is exp(2.8) ≈ 16.44. Doubling both scores leaves prediction signs unchanged but changes the ratio to exp(5.6) ≈ 270.43.

Large mass meanslow current signed score and a large loss derivative
It does not meanthe row is intrinsically difficult or mislabeled
Actual updatecan change normalized margins because relative coefficients change
Keep two cases apart. Commonly rescaling the whole vote preserves normalized margins. Adding ah4 by line search changes the relative vote and can lower one row’s normalized margin even while exponential loss decreases.

Checkpoint

Predict which row receives the largest normalized mass before looking at the numbers. Then state one reason the weight mechanism alone cannot identify the cause of that row’s difficulty.

Required note · mechanism versus diagnosis

read now

Exponential weighting tells the next learner where the current objective is sensitive. It does not identify whether the cause is noise, restricted base functions, or a persistent structure.

Construction warning

The common-scaling stress example is a mechanism-isolation construction, not a claim about a typical AdaBoost trajectory.

Link back to Block 05

The same weights become the derivative weights in coefficient space. The optimization calculation and the row-attention explanation describe the same current state.
