## Assessment

| Component | Weight |
|---|---:|

| **Total** | **100%** |

### Weekly Validation Sheets

A Validation Sheet is provided every week to help students check their
understanding. Validation Sheets and Open Investigations are distinct from the timed
Part Tests and do not contribute to the course grade unless announced otherwise.

### Part Tests

| Item | Arrangement |
|---|---|
| Number of Tests | 5, one after each Part |
| Timing | The next class after the Part is completed |
| Duration | 30 minutes per Test |
| Marks | 120 marks per Test |
| Format | 4 multiple-choice questions and 6 short-answer questions |
| Total raw marks | 600 marks |
| Course weighting | 14% per Test; 70% in total |

### Student Presentation

Student presentations take place in Weeks 11–13 and contribute **30%** of the
course grade. Each student presents an individually completed written
assignment or programming project that has been approved by the instructor in
advance. See the [Assignment page](assignment.md) for possible directions.

The detailed rubric, submission method, and student order are **TBD**. The
assignment/project is expected to be submitted by the middle of the examination
period.

## Learning Format

This course uses a **self-paced, assisted learning** approach:

1. Self-directed study with comprehensive Learning Sheets.
2. Weekly Validation Sheets for checking understanding.
3. Weekly Open Investigations for research-oriented exploration.
4. Five 30-minute Part Tests, held after the corresponding Parts.
5. Instructor and TA support during scheduled class and Tutorial time.
6. Student presentations in Weeks 11–13.
